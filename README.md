# zoo_market

Интернет-магазин для продажи зоо-товаров. Работают на Дальнем Востоке, хотят выйти на Центральную Россию. Имеют крупную сеть магазинов "Зоология". Пять крупных городов, всего 20 магазинов.
Попробовали интернет-продажи, продавали через соцсети (включая мессенджеры). Опыт в интернет-продажах: полгода. Накопили клиентскую базу полторы тысячи человек. С этой базой будут запускать маркетплейс. 
# Основа функционала: 
1) продажа еды для животных;
2) продажа сопутствующих товаров (поводки, шлейки и т.д.);
3) донаты для приютов (раз в месяц деньги капают на выбранный приют);
4) продажа породистых животных от заводчика (кошек и собак) (объявления о продаже);
5) запись в ветеринарные клиники (партнёрские клиники);
6) услуги для животных (стрижка, выгул).

Хотят начать с продажи товаров для животных, а позже нарастить функционал и перерасти в платформу.
Весь функционал - 2 года. 0-3 месяца - продажа товаров, 3-6 месяцев - донаты в приюты и продажа щенков, через год - запись в ветеринарную клинику, полтора года - услуги для животных
Есть инвестор Маша Собачкина, имеет большой опыт в выводе маркетплейсов. Бюджет на горизонте 2 лет - 15-20 млн.
Разрабатывается веб-сайт.
Будет осуществляться интеграция с курьерской службой. Можно забирать заказ самостоятельно или курьером.
20 магазинов, имеют 1С. Необходимо интегрироваться с ней, чтобы вытягивать каталог товаров.
Через 2 года хотят выйти на Центральную Россию, пока ориентируются на Дальний Восток.
Функионал: система должна рассылать уведомления (пуш, смс). Должна быть система лояльности (скидки накопительные и т.д.)
Клиента идентифицируют по номеру телефона. 
Мощностей для поддержания сайта нет - планируется поддерживать в облаке. 
Требования: масштабируемость, надёжность. 
Должна быть (только) онлайн-оплата. 
Должна быть рекомендательная система (покупатель что-то покупает, что-то лайкает. Все эти дейсвтвия фиксируются для создания рекомендаций).
